# Kiko Companion v1.0.0

The first public release of Kiko, a cute animated-face AI voice companion for Android 8.0+.

## Which APK do I download?

| APK | For |
|---|---|
| `kiko-companion-v1.0.0-arm64-v8a.apk` | **Most phones and tablets** (64-bit, roughly anything from 2017 on) |
| `kiko-companion-v1.0.0-armeabi-v7a.apk` | Older 32-bit devices and some cheap tablets |
| `kiko-companion-v1.0.0-x86_64.apk` | Emulators and x86 Chromebooks |
| `kiko-companion-v1.0.0-universal.apk` | Not sure? This one runs everywhere (bigger download) |

Check the download against `SHA256SUMS.txt`. Release APKs are signed with the project's release key, so they **can't be installed over a debug build** you compiled yourself: uninstall the debug build first (this clears its settings).

## Highlights

- **Voice chat** with Whisper STT and an LLM with tool calling (Groq by default, any OpenAI-compatible endpoint works), spoken back with lip-sync.
- **On-device wake word** ("Hey Jarvis", openWakeWord + ONNX Runtime) with custom models and threshold.
- **Chat mode** with history, Markdown, image attachments (vision models) and `.txt` / `.md` files.
- **Activity indicators**: face expressions, animations and a status pill for listening, thinking, web search, page reading, Spotify, weather, timers, apps and more.
- **Dynamic Island now-playing**, full player with album-art colors and synced lyrics.
- **Spotify control**: local media keys, the official Web API, or the self-hosted [spotapi-backend](https://github.com/ejatapibeda/spotapi-backend).
- **Weather-reactive face** (rain, six-armed snowflakes, heat haze) with sneezing, shivering and overheating reactions.
- **Dance mode**, sleep animation, touch and motion reactions.
- **TTS fallback chain**: free TikTok voices → TikTok session → ElevenLabs / OpenAI-compatible → Android TTS.
- **Mic processing**: noise suppression, echo cancellation, AGC and a sensitivity slider.
- **Free web search** with no key (Tavily keyless → SearXNG → DuckDuckGo → Wikipedia) plus optional keyed providers.
- **English and Indonesian**, encrypted key storage, no keys bundled or logged.
- The app version is shown in **Settings → About**, with a link to this Releases page.
